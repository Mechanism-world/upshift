## `agent.json` — 3 edits

1. `name`: `"agent"` → `"quickstart-agent"` (adapt took the directory name; `agent.py` defines
   no agent name — `name` is a constructor argument, `agent.py:38`).
2. `model`: `"claude-sonnet-4-20250514"` → `"claude-fable-5"`. Not a correction: adapt read the
   right default (`agent.py:27`); the model is the variable under test.
3. `params`: dropped `"temperature": 1.0`. Adapt extracted it correctly (`agent.py:29/89`); both
   Fables 400 on non-default sampling params, on baseline *and* candidate, so keeping it would
   measure the wrong thing. Rationale in ATTRIBUTION.md.

Kept unchanged and confirmed correct: `endpoint: "messages"` (`agent.py:117`),
`max_tokens: 4096` (`agent.py:28`), `max_turns: 12` (adapt's own default — upstream's loop is
unbounded, `agent.py:104`, so there is nothing to match).

## `system_prompt.txt` — 1 edit

Replaced adapt's placeholder (`TODO(adapt): no system prompt could be traced to this
repository's source.`) with `agent_demo.ipynb` cell 5, verbatim minus the web-search line.

adapt was **right** to leave a hole: it never read the notebook — no `.ipynb` appears anywhere
in the evidence table of its run (16 files scanned, 14 ranked, all `.py`/`.md`), and `agent.py`

"undetermined beats guessed" contract behaving as designed, and the one-line cost of it.

## `backend.py` — full rewrite

adapt emitted its generic `TOOL_SPECS` engine: `file_read` / `file_write` mapped onto built-in
`file_read`/`file_write` kinds over a `{"files": {...}}` state (flagged REVIEW, semantics never
machine-verified) and `calculator` / `think` as `{"error": "TODO(adapt): not implemented …"}`
stubs, because "the allowed backend categories do not include a no-op or constant-return tool
backend".

The rewrite: all four tools implemented against the cited upstream sources, mirroring the
operation dispatch, `max_lines` truncation, the `📄`/`📁` listing format and every reply and
error sentence; `state()` extended with the `writes` / `write_count` log the over-acting case
needs. The stub for `think` was a two-line fix (`return "Thinking complete!"`); the stub for
`calculator` was a faithful port of `calculator_mcp.py:25-51`.

Honest read of the adapt output here: the two "implemented" tools were the *right shape* but
would have failed every case — a `read` operation returned `{"path", "content"}` rather than
upstream's bare string, and neither honoured `operation`, `max_lines` or `pattern`.
