## a. Vendored and derived material in this repository

Each `agents/<name>/` directory is an *adaptation* of an upstream agent into upshift's
five-file contract (`agent.json`, `system_prompt.txt`, `tools.json`, `backend.py`,
`cases/cases.json`). Each one carries its own `ATTRIBUTION.md` recording, line by line,
which upstream file every artifact came from and every place we deviate. Those files are
the authoritative per-artifact record; this section is the license summary.

## b. Quoted documentation and API text

Two kinds of text in this repository are quoted from Anthropic's published material rather
than written by us:

1. **Repair sentences in [`src/upshift/repair/playbook.py`](src/upshift/repair/playbook.py).**
   The constants `FORCED_TOOL_INSTRUCTION`, `FORCED_ANY_INSTRUCTION`, `BATCH_BLOCK` and
   `VERIFICATION_NUDGE_BLOCK` reproduce, verbatim, wording from Anthropic's published Claude
   Fable 5.1 migration and prompting guidance. They are quoted verbatim deliberately: the
   exact wording *is* the repair, and paraphrasing it would change what the tool is testing.
   The module says so at the definition site.
2. **API error strings.** The 400-response strings encoded as detector signatures (for
   example `tool_choice: type "tool" and "any" are not supported for this model.`) are
   verbatim output returned by the Anthropic API. They are matched on, and printed in
   reports, so that a user can recognize the failure they will see in their own logs.

Sources are cited in [`DESIGN.md`](DESIGN.md) (§ "Anthropic provider"):
`platform.claude.com/docs/en/models/fable-5-1/{whats-new-fable-5-1,migration-guide}`,
`platform.claude.com/docs/en/build-with-claude/prompt-engineering/prompting-claude-fable-5-1`,
`platform.claude.com/docs/en/build-with-claude/effort`, and
`platform.claude.com/docs/en/agents-and-tools/tool-use/{define-tools,handle-tool-calls}`.

These excerpts are quoted for **interoperability and attribution**: a tool that repairs an
agent against documented guidance has to use the documented words. No ownership of this text
is claimed, and no endorsement by Anthropic is implied. All rights in it remain with
Anthropic, PBC.
